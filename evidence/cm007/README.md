# CM-007 evidence directory

This directory is reserved for reviewed, concise physical qualification evidence.
The preparation branch contains no hardware result.

Keep raw serial logs, one-second telemetry and long WAVs under ignored
`build/cm007/`. After review, copy only the relevant `summary.json` files and small
representative contact examples here. Preserve their `SHA256SUMS` provenance and
record the tested Git commit, fixture geometry, audio settings and operator notes.

A summary using schema `contactmic.cm007.summary.v1` is generated by
`tools/cm007_qualify.py`. Evidence is not accepted merely because its derived
status says `pass`; issue #7 requires review of the raw run and the complete high,
medium, axis/range, LED and contact-response programme.
